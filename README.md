# HK Go OS: Updates

Hier liegen nur die Versionsangaben für HK Go OS (Windows-Programm im Büro des Ambulanten Pflegedienstes Heike Kühn).

- `version.json`: aktuelle Version, Download-Adresse und SHA-256-Prüfsumme.
- Die Programmdateien (ZIP) hängen an den Releases.

HK Go OS prüft diese Datei selbst und zeigt „Neue Version verfügbar“. Vor jedem Update werden die Daten gesichert.

In diesem Repository liegen keine Daten von Mitarbeitern oder Klienten, keine Passwörter und keine Schlüssel.
